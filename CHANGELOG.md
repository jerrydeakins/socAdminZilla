## 1.0.0

First stable Firefox extension release.

This release consolidates the functionality developed during the 0.3.x series: VK toolbar, source and home-community management, bounded post collection, moderation/editor, publication queue, manual-assisted VK publication, configuration import/export, and local community-avatar caching.
