# SocAdmin

[🇬🇧 English](README.md) · [🇷🇺 Русский](README.ru.md)

Расширение Firefox для администрирования сообществ ВКонтакте.

SocAdmin — панель инструментов, встроенная непосредственно в страницы VK. Расширение работает с авторизованным веб-интерфейсом VK и не использует VK API.

## Текущая версия

**1.0.1** — текущая стабильная версия расширения.

В текущей версии доступны:

- локальное управление сообществами-источниками и домашними сообществами;
- сбор последних публикаций из выбранных сообществ VK с заданным ограничением количества;
- модерация и редактирование собранных публикаций;
- хэштеги, эмодзи и шаблоны в редакторе;
- локальная очередь публикаций;
- ручной процесс публикации в VK с кнопкой **Авто**, которая заполняет форму публикации текстом и изображением, после чего останавливается для подтверждения и публикации пользователем;
- локальное кэширование аватаров сообществ;
- импорт и экспорт конфигурации;
- работа только на `vk.ru` и `vk.com`.

В версии 1.0.1 также обновлены иконки расширения.

## Установка для разработки

1. Откройте Firefox → `about:debugging`.
2. Выберите **This Firefox**.
3. Нажмите **Load Temporary Add-on**.
4. Выберите `manifest.json` из репозитория.

Временная установка предназначена для разработки. Для постоянной установки и автоматических обновлений используется подписанная сборка расширения.

## Разработка

Расширение по возможности использует стабильные семантические элементы DOM, предоставляемые VK. Динамические CSS-классы VK не следует использовать в качестве селекторов, если доступны семантический атрибут, текст, роль или `data-testid`.

Будущие улучшения и обнаруженные ошибки отслеживаются через GitHub Issues.
